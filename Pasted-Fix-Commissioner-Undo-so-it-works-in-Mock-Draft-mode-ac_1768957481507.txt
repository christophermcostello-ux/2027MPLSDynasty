Fix Commissioner Undo so it works in Mock Draft mode across all clients

Currently Undo works locally, but in Mock Draft mode it does not propagate and/or does not modify the authoritative mock draft state. Update the implementation so Undo in Mock behaves exactly like Draft mode, but using the Mock shared state/event pipeline.

Expected behavior

When the commissioner clicks Undo Last Pick in Mock:

The last pick is removed from the authoritative Mock pick history (server/shared state, not just local UI).

The drafted player is removed from draftedIds/draftedMap.

The on-the-clock team/pick number rolls back by 1.

All connected clients update immediately without refresh:

The player reappears in the player pool and TIERS grids.

The player becomes queue-able again.

Any client queue reconciliation should not re-add the player automatically, but it must stop treating them as drafted.
